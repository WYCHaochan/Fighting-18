# Fighting-18
[简体中文](README_CN.md) | **English**
### Hello everyone, welcome to the repository of my game project "Fighting-18".
This project was an early personal game development attempt. The original version is no longer under active development and has been archived. The game was originally developed using Easy Language, a Chinese programming language, and implemented a basic local two-player battle gameplay. Due to the early stage of development, many aspects of the project, such as UI, sound effects, and animations, were not fully completed, resulting in a relatively low level of overall polish.
I am currently considering redesigning and developing a remake version using the Unity engine. The future remake may include comprehensive improvements to gameplay mechanics, systems, and visual presentation.
This repository is currently preserved as an archived version of the old project, mainly to document my early learning and game development experience.
